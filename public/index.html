CarFlow

Ви на порту 3000 без збірки фронту. Стара статична сторінка більше не дублює новий React-інтерфейс. Щоб побачити повний новий інтерфейс (React SPA):
  • Найпростіше: у каталозі проєкту виконайте npm run dev і відкрийте http://127.0.0.1:5173/ (API підніметься автоматично).
  • Лише порт 3000: npm run start:with-ui, потім оновіть цю сторінку.
  • Вручну: у двох терміналах npm start та npm run frontend:dev, браузер — знову 5173.

Застарілі окремі HTML (без нового SPA):

  • Адмін-панель (legacy)
  • Вхід (legacy)
  • Реєстрація (legacy)
